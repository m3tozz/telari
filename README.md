# Kurulum
> telari go dilinde yazılmıştır, go'yu sisteminizize kurmak için https://go.dev/doc/install adresini ziyaret edebilirsiniz
```bash
git clone https://github.com/m3tozz/telari
```
```bash
cd telari
```
```bash
go run telari.go
```
